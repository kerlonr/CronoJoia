## Sobre

Cronômetro em tela cheia feito para controlar o tempo de apresentações de **7 minutos**. Os
números ocupam a tela inteira para serem vistos de longe por quem está apresentando.

## Visão Geral

- contagem de **0:00 até 7:00**, parando sozinho no limite
- números **amarelos** no último minuto e **vermelhos** nos últimos 30 segundos
- botões **Iniciar**, **Parar** e **Resetar**

## Rodando Localmente

Projeto estático, sem dependências: basta abrir o `index.html` no navegador.
